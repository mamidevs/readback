# Teammates at other providers

The host selects the opposite provider automatically. This file is optional.
Copy it to `~/logbook/TEAMMATES.md` to change the model or effort for a host.
A teammate at another provider sees the contract, the handoff and the repository folder.

Each row is: role | host | provider | model | effort
The first matching row is used. Host and provider must differ.
The Claude judge must remain in the Fable family. A missing row uses the defaults below.
Legacy four-column rows still apply to the opposite host of their provider.

judge | claude | codex | gpt-6-astra | high
judge | codex | claude | fable | high
