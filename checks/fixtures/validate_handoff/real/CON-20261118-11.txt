Out of scope: the hooks, `scripts/outside_judge.py`, the settings module, `scripts/sync.py`, who may call these functions, the existing test files, any commit, any push.
Limits, stated on purpose: the files are local and untrusted; the agent runs as the same user and can write them. The module does not know who the owner is; the hook of P3 decides what an owner event is. Codex session ids rest on documentation only. A crash after `consume` and before the helper has stored its reservation loses that authorization, and the owner gives it again; the lead keeps this simple on purpose, because the loss lowers the number of judge attempts and never raises it, and a joint journal of two stores is more code than this safety net is worth. Consumers use the functions of this module and do not edit the files.
D1. Place and ids. `<base>/<host>-<session id>.json`; `base` is an argument, default `~/logbook/.readback/sessions`. `host` is `claude` or `codex`. A session id is safe when it matches `[A-Za-z0-9][A-Za-z0-9._-]{0,127}`. Anything else raises `SessionError("INVALID_ID")`.
D2. State. Exactly the keys `{"schema_version": 1, "host", "session_id", "mode", "mode_event", "authorizations", "processed_events"}`; `schema_version` is the integer 1, not a boolean; an event id is a non-empty string; `processed_events` is the list of the event ids of every `authorize` that was stored, kept after its authorization is consumed, until `clear`. `authorizations` and `processed_events` are lists; `mode_event` and each authorization have exactly their named keys. `mode` is null, `off`, `gate` or `each`. `mode_event` is null or `{"id", "at"}`; a `set_mode` to null keeps it as the provenance of that change. An authorization is `{"event_id", "at", "project_home", "repository", "lineage", "tier", "settings_digest"}`; `tier` is `step` or `gate`; the five target fields are `project_home`, `repository`, `lineage`, `tier` and `settings_digest`. `at` is UTC, `YYYY-MM-DDTHH:MM:SSZ`, given by the caller.
D3. `read(host, session_id, base)` returns `("absent", None)`, `("valid", state)` or `("invalid", reason)`. It raises only for an unsafe id.
D4. `set_mode(host, session_id, mode, event_id, at, base)` writes the mode and `mode_event`. When `mode_event.id` already equals `event_id`, it changes nothing. On an invalid file it raises `SessionError("INVALID_STATE")` and writes nothing.
D5. `authorize(host, session_id, event_id, at, project_home, repository, lineage, tier, settings_digest, base)` appends one authorization and adds `event_id` to `processed_events`, unless `processed_events` holds it already. On an invalid file it raises `SessionError("INVALID_STATE")` and writes nothing.
D6. `consume(host, session_id, project_home, repository, lineage, tier, settings_digest, base)` returns the earliest appended matching authorization and removes it, or returns null. No file and an invalid file give null.
D7. `clear(host, session_id, base)` removes the state file under the same lock. The hook of P3 calls it on resume, on fork and at the end of a session, so that overrides and unused authorizations end there.
D8. Every mutation holds an exclusive lock on `<base>/<host>-<session id>.lock`, a file that stays. A publication of state writes and syncs a temporary file in `<base>` with mode 0600, renames it, then syncs the folder. `clear` unlinks the state file and syncs the folder. `read` takes only the exact state file name.
D9. `session_id_from_env(host, env)` returns `env["CLAUDE_CODE_SESSION_ID"]` for `claude` and `env["CODEX_SESSION_ID"]` for `codex` when the value is a safe id, else null. A missing id turns the session lookup off and creates no file; an unsafe id that a caller passes to another function raises `INVALID_ID`.
D10. Invalid files of ACC-1: not JSON; a JSON list; `schema_version` 2; a `host` or `session_id` that differs from the file name; a `mode` outside the list; an authorization with a missing field; an authorization with a `tier` outside the list; an unknown key; a `schema_version` of `true`; an empty event id; an `at` that is not a UTC time of the form of D2; a field of an authorization that is not a string.
